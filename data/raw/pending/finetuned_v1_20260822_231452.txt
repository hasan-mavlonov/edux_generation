<problem>Agar $x + \frac{1}{x} = 5$ bo'lsa, $x^4 + \frac{1}{x^4}$ ifodaning qiymatini toping.</problem>
<choices>A) 23  B) 26  C) 30  D) 25</choices>
<solution>$x + \frac{1}{x} = 5$ bo'lsa, ikkinchi darajali qisqa ko'paytuvchini o'tkazamiz:
$(x + \frac{1}{x})^2 = x^2 + 2 \cdot x \cdot \frac{1}{x} + \frac{1}{x^2} \implies 5^2 = x^2 + 2 + \frac{1}{x^2} \implies x^2 + \frac{1}{x^2} = 25 - 2 = 23$.
Endi uning kvadratini hosil qilamiz:
$(x^2 + \frac{1}{x^2})^2 = x^4 + 2 \cdot x^2 \cdot \frac{1}{x^2} + \frac{1}{x^4} \implies 23^2 = x^4 + 2 + \frac{1}{x^4}$.
Ikkala tarafni 2 ga ayiramiz:
$x^4 + \frac{1}{x^4} = 529 - 2 = 527$.
Demak, javob 527 bo'ladi.</solution>
<answer>527</answer>

<problem>$a^2 + b^2 + c^2 - ab - bc - ca$ ifodaning qiymatini hisoblang, agar $a + b + c = 1$ va $ab + bc + ca = -1$ berilgan.</problem>
<choices>A) 1  B) 2  C) 3  D) 4</choices>
<solution>Identsiyani qulay ravishda yozamiz:
$a^2 + b^2 + c^2 - ab - bc - ca = \frac{1}{2}[(a - b)^2 + (b - c)^2 + (c - a)^2]$
Bu ifodaning qiymati 0 dan katta bo'lgan bo'lib, tenglik faqat $a = b = c$ bo'lganda 0 ga teng. Ushbu shart qismi $a + b + c = 1$ va $ab + bc + ca = -1$ usulida yechilsa, o'zgaruvchilarning har biri $a = b = c = \frac{1}{3}$ bo'ladi. Endi $a^2 + b^2 + c^2$ ning qiymatini topamiz:
$(a^2 + b^2 + c^2) = \frac{1}{3^2} + \frac{1}{3^2} + \frac{1}{3^2} = 3 \cdot \frac{1}{9} = \frac{1}{3}$.
$ab + bc + ca = -1$ tenglamadan $ab + bc + ca = 3 \cdot \frac{1}{3} \cdot \frac{1}{3} = \frac{1}{3}$, bu esa berilgan $-1$ qiymatga teng emas. Shuning uchun identsiyani qo'llash yechim yo'q. Bunday holda ifodaning qiymati $a^2 + b^2 + c^2 - ab - bc - ca = (a + b + c)^2 - 3(ab + bc + ca) = 1^2 - 3 \cdot (-1) = 1 + 3 = 4$ ga teng.</solution>
<answer>D</answer>
