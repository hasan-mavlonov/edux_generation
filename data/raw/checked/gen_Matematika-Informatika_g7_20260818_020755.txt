<solution>Uch xonali sonni 100a + 10b + c ko'rinishida yozamiz. Masala shartiga ko'ra:
100a + 10b + c = 15(a + b + c)
Qavslarni ochib, o'xshash hadlarni ixchamlaymiz:
100a + 10b + c = 15a + 15b + 15c
85a = 5b + 14c
Raqamlar b ≤ 9 va c ≤ 9 bo'lgani uchun, o'ng tomonning maksimal qiymati: 5(9) + 14(9) = 45 + 126 = 171.

Agar a = 1 bo'lsa: 85 = 5b + 14c. 85 va 5b sonlari 5 ga bo'linadi, demak 14c ham 5 ga bo'linadi (c=0 yoki 5). 
c = 0 da: 5b = 85 → b = 17 (xato).
c = 5 da: 14(5) = 70. 5b = 85 - 70 = 15 → b = 3. 
Demak, a = 1, b = 3, c = 5. Qidirilayotgan son: 135.</solution>

<problem>x va y haqiqiy sonlar bo'lsa, 2x² + 2xy + y² - 2x + 2y + 2026 ifodaning eng kichik qiymatini toping.</problem>
<choices>A) 2021  B) 2026  C) 2025  D) 2020</choices>
<solution>Berilgan algebraik ifodani to'la kvadratlarga ajratib soddalashtiramiz. 
2x² + 2xy + y² - 2x + 2y + 2026 ifodadan oldin (x+y+1)² ni ajratishga harakat qilamiz:
(x + y + 1)² = x² + y² + 1 + 2xy + 2x + 2y.
Asl ifodadan shu qismini ayirsak:
(2x² + 2xy + y² - 2x + 2y + 2026) - (x² + y² + 2xy + 2x + 2y + 1) = x² - 4x + 2025.
Endi x² - 4x + 2025 qismini to'la kvadratga keltiramiz:
x² - 4x + 4 + 2021 = (x - 2)² + 2021.
Demak, butun ifoda quyidagicha yoziladi:
f(x,y) = (x + y + 1)² + (x - 2)² + 2021.
Kvadratlar har doim manfiy bo'lmagani uchun (≥ 0), ifodaning eng kichik qiymati ikkala qavs ichi nolga teng bo'lganda erishiladi:
x - 2 = 0 → x = 2,
x + y + 1 = 0 → 2 + y + 1 = 0 → y = -3.
Bu nuqtada ifodaning qiymati 0 + 0 + 2021 = 2021 bo'ladi.</solution>
