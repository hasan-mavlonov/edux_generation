<problem>x, y va z musbat haqiqiy sonlar bo'lib, quyidagi tengliklarni qanoatlantiradi:
x + 1/y = 4
y + 1/z = 1
z + 1/x = 7/3
x·y·z ko'paytmaning qiymatini toping.</problem>
<choices>A) 2  B) 1  C) 3/2  D) 5/3</choices>
<solution>Uchala tenglamani o'zaro ko'paytiramiz:
(x + 1/y)(y + 1/z)(z + 1/x) = 4 · 1 · 7/3 = 28/3.
Qavslarni ochamiz:
xyz + x + y + z + 1/x + 1/y + 1/z + 1/(xyz) = 28/3.
Buni qayta guruhlaymiz: xyz + (x + 1/y) + (y + 1/z) + (z + 1/x) + 1/(xyz).
Bizga (x + 1/y) + (y + 1/z) + (z + 1/x) = 4 + 1 + 7/3 = 22/3 ekanligi ma'lum.
O'rniga qo'yamiz: xyz + 22/3 + 1/(xyz) = 28/3.
Bundan xyz + 1/(xyz) = 2 kelib chiqadi.
t = xyz desak, t + 1/t = 2. Uni t ga ko'paytirib, t² - 2t + 1 = 0 holatga keltiramiz. (t - 1)² = 0, ya'ni t = 1.
Demak, xyz = 1.</solution>

1) Oldinga N qadam yurish
2) O'ngga 90 gradus burilish
3) N ning qiymatini 2 ga oshirish.

Y (vertikal) o'zgarishi: Shimol (k) - Janub (k+4) = -4.

12-qadamdan so'ng N = 1 + 12·2 = 25 bo'ladi.
13-qadam: Shimolga 25. Y = -12 + 25 = 13.
14-qadam: Sharqqa 27. X = -12 + 27 = 15.
15-qadam: Janubga 29. Y = 13 - 29 = -16.
Yakuniy manzil: X = 15, Y = -16.
Ular yig'indisi: 15 + (-16) = -1.</solution>
