<problem>Tenglamani yeching: (2x + 3) / 5 - (x - 1) / 3 = 2</problem>
<choices>A) 12  B) 16  C) 18  D) 14</choices>
<solution>Tenglamadagi kasrlarning maxrajlari 5 va 3 ga teng, ularning eng kichik umumiy karralisi 15. Tenglamaning ikkala qismini 15 ga ko'paytiramiz:
15 · ((2x + 3) / 5) - 15 · ((x - 1) / 3) = 15 · 2
3(2x + 3) - 5(x - 1) = 30
Qavslarni ochamiz:
6x + 9 - 5x + 5 = 30
x + 14 = 30
x = 30 - 14 = 16.
Tekshirish: (2·16+3)/5 - (16-1)/3 = 35/5 - 15/3 = 7 - 5 = 2. Natija to'g'ri.</solution>

<problem>Mantiqiy ifoda berilgan: F = (A AND (NOT B)) OR (NOT (A OR C)). Bu yerda A, B va C mantiqiy o'zgaruvchilar. Ushbu ifoda rost (ya'ni F=1) bo'lishi uchun A, B, C o'zgaruvchilarining qabul qilishi mumkin bo'lgan turli xil qiymatlar to'plamlari (uchliklar) soni nechta?</problem>
<choices>A) 3  B) 4  C) 5  D) 2</choices>
<solution>Ifodani soddalashtiramiz. De Morgan qonuniga ko'ra NOT (A OR C) = (NOT A) AND (NOT C).
Ifoda: F = (A AND (NOT B)) OR ((NOT A) AND (NOT C)).
OR (yoki) amali rost bo'lishi uchun qo'shiluvchilardan kamida biri rost bo'lishi kerak:
1-holat: A AND (NOT B) = 1. Bu A = 1 va B = 0 bo'lganda o'rinli. C o'zgaruvchisi bu holatda ta'sir qilmaydi, u 0 yoki 1 bo'lishi mumkin. Uchliklar: (1, 0, 0) va (1, 0, 1). Jami 2 ta.
2-holat: (NOT A) AND (NOT C) = 1. Bu A = 0 va C = 0 bo'lganda o'rinli. B o'zgaruvchisi 0 yoki 1 bo'lishi mumkin. Uchliklar: (0, 0, 0) va (0, 1, 0). Jami 2 ta.
Bu ikki holatda A ning qiymati turlicha (birida 1, ikkinchisida 0), shuning uchun ular bir vaqtda sodir bo'lishi mumkin emas.
Jami qanoatlantiruvchi uchliklar soni: 2 + 2 = 4 ta.</solution>

<problem>x va y haqiqiy sonlari uchun x - y = 4 va x³ - y³ = 208 ekanligi ma'lum bo'lsa, (x + y)² ifodaning qiymatini toping.</problem>
<choices>A) 64  B) 81  C) 36  D) 100</choices>
<solution>Kublar ayirmasi formulasidan foydalanamiz:
x³ - y³ = (x - y)(x² + xy + y²).
Berilgan qiymatlarni qo'yamiz: 208 = 4 · (x² + xy + y²), bundan x² + xy + y² = 52 ekani kelib chiqadi.
Ikkinchi tomondan, (x - y)² = 4² = 16 ekanidan x² - 2xy + y² = 16 tenglikni olamiz.
Bu ikki tenglikni bir-biridan ayiramiz:
(x² + xy + y²) - (x² - 2xy + y²) = 52 - 16
3xy = 36, ya'ni xy = 12.
Endi (x + y)² qiymatini topish uchun quyidagi ayniyatdan foydalanamiz:
(x + y)² = (x - y)² + 4xy.
Ma'lum qiymatlarni o'rniga qo'yamiz:
(x + y)² = 16 + 4 · 12 = 16 + 48 = 64.</solution>

<problem>To'g'ri to'rtburchakning ichida uning tomonlariga parallel bo'lgan bitta vertikal va bitta gorizontal kesma o'tkazilib, u to'rtta kichik to'g'ri to'rtburchakka ajratildi. Agar chap-yuqori to'rtburchakning perimetri 14 ga, o'ng-yuqori to'rtburchakning perimetri 20 ga va chap-pastki to'rtburchakning perimetri 16 ga teng bo'lsa, o'ng-pastki to'rtburchakning perimetrini toping.</problem>
<choices>A) 22  B) 18  C) 24  D) 26</choices>
<solution>Kichik to'rtburchaklarning gorizontal o'lchamlari (kengliklari) a va b, vertikal o'lchamlari (balandliklari) esa c va d bo'lsin.
Chap-yuqori to'rtburchak perimetri: 2(a + c) = 14 => a + c = 7.
O'ng-yuqori to'rtburchak perimetri: 2(b + c) = 20 => b + c = 10.
Chap-pastki to'rtburchak perimetri: 2(a + d) = 16 => a + d = 8.
O'ng-pastki to'rtburchakning perimetri P = 2(b + d) ni topishimiz kerak.
(b + c) + (a + d) - (a + c) = b + c + a + d - a - c = b + d ekanligidan foydalanamiz:
b + d = 10 + 8 - 7 = 11.
U holda P = 2(b + d) = 2 · 11 = 22.
Qarama-qarshi to'rtburchaklar perimetrlari yig'indisi o'zaro teng degan teoremadan ham foydalansa bo'ladi: P_chap_yuqori + P_o'ng_past = P_o'ng_yuqori + P_chap_past => 14 + P = 20 + 16 => P = 36 - 14 = 22.</solution>
