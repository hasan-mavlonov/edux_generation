<problem>$A, B, C$ mantiqiy o'zgaruvchilar bo'lsin. $(A \lor \neg B) \land (B \lor C) \land (\neg A \lor \neg C) = 1$ tenglikni qanoatlantiradigan $(A, B, C)$ mantiqiy qiymatlar uchliklari soni nechta?</problem>
<choices>A) 1  B) 2  C) 3  D) 4</choices>
<solution>Ifodaning qiymati 1 bo'lishi uchun barcha uchta qavs bir vaqtda 1 bo'lishi kerak.
1) Agar $A=0$ bo'lsa: $A \lor \neg B = \neg B = 1 \implies B = 0$.
   $B \lor C = 0 \lor C = C = 1 \implies C = 1$.
   Tekshirish: $\neg A \lor \neg C = 1 \lor 0 = 1$. $(0, 0, 1)$ uchligi mos keladi.
2) Agar $A=1$ bo'lsa: $\neg A \lor \neg C = 0 \lor \neg C = \neg C = 1 \implies C = 0$.
   $B \lor C = B \lor 0 = B = 1 \implies B = 1$.
   Tekshirish: $A \lor \neg B = 1 \lor 0 = 1$. $(1, 1, 0)$ uchligi mos keladi.
Jami 2 ta yechim bor.</solution>
<answer>B</answer>
</example>

<problem>$n$ natural soni uchun $\dfrac{n^2 + 3n + 25}{n+3}$ ifodaning qiymati butun son bo'ladigan $n$ ning eng katta natural qiymatini toping.</problem>
<solution>Kasrni butun qismini ajratamiz:
$\dfrac{n^2 + 3n + 25}{n+3} = \dfrac{n(n+3) + 25}{n+3} = n + \dfrac{25}{n+3}$.
Ifoda qiymati butun son bo'lishi uchun $n+3$ soni 25 ning bo'luvchisi bo'lishi kerak.
25 ning natural bo'luvchilari: 1, 5, 25.
$n$ natural son bo'lgani uchun $n \ge 1 \implies n+3 \ge 4$.
Shuning uchun $n+3$ qiymati 5 yoki 25 bo'lishi mumkin.
$n+3 = 25 \implies n = 22$. En katta natural qiymat 22 dir.</solution>
<answer>22</answer>
</example>
